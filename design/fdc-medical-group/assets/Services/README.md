# Services

66px two-tone illustrations for the clinic's six service lines: đa khoa, khám tại nhà, tiêm chủng vắc xin, khám sức khỏe doanh nghiệp, xét nghiệm tại nhà, khám BHYT. Inks: near-black outline and FDC blue #1c75bc, baked in, so they stay blue in the nursing home theme. Use on white inside ServiceCard.
