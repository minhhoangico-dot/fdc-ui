# HotlineCard

A tap-to-call hotline, the most important contact on every FDC page.

- **inline** (default): pink phone disc, small label and the number in `accent-600`. Use in headers and sticky bars.
- **framed**: the nursing home's footer block, a `brand-600` frame with the label set into the top edge and a 26px number. Use in contact sections.

Pass the number exactly as it should read ("024 35 430 430" for the clinic, "096 583 7777" for the nursing home); the `tel:` link strips spaces. The number stays `accent-600` pink in both themes. Do not put two hotlines side by side on one screen.
