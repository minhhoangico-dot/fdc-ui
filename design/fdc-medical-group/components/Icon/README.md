# Icon

A single-ink SVG glyph that takes the surrounding text color, drawn from the 24 IcoFont glyphs both FDC sites already use.

Set color on the parent (`color: var(--text-brand)`), never on the icon. Default size is 16px; use 12–14px inline with text, 24–40px in cards. Decorative icons are hidden from screen readers; pass `title` when the icon is the only label (an icon-only button). The same glyphs are in Assets › Icons as SVG files for other tools.
