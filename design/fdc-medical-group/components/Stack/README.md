# Stack

Vertical layout that owns the spacing between its children, so no component needs an outer margin.

Set `gap` to a space step (5, 10, 15, 20, 30, 40, 50 → `space-*`). Use it for form fields (20–30), card contents (10–15) and page sections (40–50). `as="ul"` or `"form"` keeps the right semantics.
