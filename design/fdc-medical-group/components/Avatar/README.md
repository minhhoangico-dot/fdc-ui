# Avatar

A round person image, or initials on `surface-tint` when there is no photo.

Pass `name` so the initials and alt text are right; initials come from the last two words ("Bùi Hiền" → BH). `ring` adds the 5px `decor-ring` border used on the nursing home testimonials. Use resident and patient photos only with written consent; initials are the safe default.
