# WorkingHours

Opening hours as a short labeled list with a calendar icon, as in the clinic header.

Pass `rows` (`label`, `hours`) and an optional `note` such as "Tất cả các ngày trong tuần". Write times as 07:00–20:00 with an en dash. The title is `leaf-700` green; times are bold `ink` with tabular digits. The site set the times in pink; here pink stays reserved for the hotline.
