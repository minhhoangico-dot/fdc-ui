# SpecialtyTile

A 60px row linking to a specialty or care type: a `brand-600` square holding a white icon, then the name.

Use in a 2-column list on `surface-alt`. Pass `image` from Assets › Specialties (white 60px icons) or an `icon` name. The square follows the theme, so the same tiles turn orange on nursing home pages. Keep names to one line ("Khoa nhi", "Tai - Mũi - Họng").
