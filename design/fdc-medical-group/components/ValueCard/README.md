# ValueCard

A bordered box for one brand value or promise, from the nursing home's F-D-C (Family, Doctor, Center) row.

Use three in a row. The border is `brand-600`; the title is `group-600`, the group blue that stays blue in every theme, so the nursing home's orange frame keeps the family link. Pass `title` ("F – Family") and the text as children; keep text under 40 words.
